# 가곡동 이야기책 만들기 (AI를 활용한 가곡동 이야기 책 만들기 교육용)

「AI를 활용한 가곡동 이야기 책 만들기」 교육(상상창고, 8회차) 참여자가 휴대폰으로 들어와 **이야기 지도**에 기억 속 장소를 남기고, **AI 인터뷰**로 기억을 꺼내고, **12쪽 구성표**(제목면 → 글·그림 5쌍 → 지은이 소개)로 책 뼈대를 잡은 뒤, 글을 쓰고 **AI 교정**을 받고, **공동 그림체**로 **AI 그림(ChatGPT 이미지)**을 만들어 쪽에 넣고, 신국판(152×225mm) 공동 이야기책 PDF까지 만드는 웹앱입니다.
「마을작가 책 만들기」(bookclassapp) 앱을 복사해 만든 **별도 앱**이라 데이터가 섞이지 않습니다(테이블 접두어 `ys_`, 마을작가 앱은 `bk_`).
빌드 과정이 없는 정적 파일 + 서버 함수 세 개라서 **Vercel**에 올려야 합니다.

| 파일 | 하는 일 |
|---|---|
| `schema.sql` | Supabase 통합 프로젝트에 실행 (테이블·함수·사진 저장소, 접두어 `ys_`). 여러 번 실행해도 기존 데이터는 그대로예요 |
| `config.js` | Supabase 주소·키, 앱 이름, AI 그림 하루 장수 표시, 이야기 지도 처음 위치 |
| `curriculum.js` | 8회차 수업 되짚기 카드 (날짜 `day`를 채우면 회차 옆에 보여요) |
| `fonts.js` | 고를 수 있는 글꼴 목록 |
| `api/proof.js` | AI 교정 (Claude) |
| `api/interview.js` | AI 인터뷰 · 글감 정리 · 12쪽 흐름 제안 (Claude) |
| `api/image.js` | AI 그림 만들기 (OpenAI 이미지 API = ChatGPT 이미지) |
| `api/_sb.js`, `vercel.json` | 서버 함수 공용 도구, 실행 시간 설정 |
| `index.html`, `app.js`, `book.js`, `extra.js`, `style.css` | 웹앱 본체 (`extra.js` = 이야기 지도·AI 인터뷰·그림체·AI 그림·12쪽 구성표) |

## 설치 (20분 정도)

1. **Supabase 통합 프로젝트** → SQL Editor → New query → `schema.sql` 전체 붙여넣기 → 맨 아래 운영자 이름·비밀번호(`'운영자'`, `'0000'`)를 바꾸고 **Run**.
   새 프로젝트를 만들 필요 없이 마을작가 앱·별동산 등과 같은 프로젝트에 넣으면 됩니다(추가 비용 없음). 테이블이 모두 `ys_`로 시작해서 다른 앱은 건드리지 않아요.
2. `config.js`에는 통합 프로젝트의 **Project URL**과 **publishable 키**가 이미 들어 있습니다. `service_role`·`secret` 키는 절대 넣지 마세요.
3. GitHub 새 저장소(예: `gagok-story`) → Add file → Upload files로 **폴더째** 올립니다(`api` 폴더가 꼭 같이 올라가야 함).
4. Vercel → Add New → Project → 저장소 Import → Framework Preset **Other**, 빌드 설정은 비워 두고,
   **Environment Variables**에 아래를 넣은 뒤 Deploy (값은 `배포-환경변수.txt`에 적어 두었음):
   - `ANTHROPIC_API_KEY` — Claude API 키 (마을작가 앱과 같은 키를 써도 됨)
   - `OPENAI_API_KEY` — OpenAI API 키 (platform.openai.com → API keys에서 발급, 결제 수단 등록·충전 필요)
   - `SUPABASE_URL` — `https://snaldhxucwsaifqrccih.supabase.co`
   - `SUPABASE_ANON_KEY` — `config.js`의 publishable 키와 같은 값
   - (선택) `IMAGE_MODEL` 비우면 `gpt-image-2` → `gpt-image-1` → `gpt-image-1-mini` 순서로 시도 · `IMAGE_QUALITY` 기본 `medium`(low/medium/high) · `PROOF_MODEL`·`INTERVIEW_MODEL` 기본 `claude-sonnet-5-5`
   배포 뒤에 환경변수를 바꿨다면 Deployments → Redeploy를 한 번 눌러야 반영됩니다.
   OpenAI는 처음 쓰는 조직이면 이미지 모델을 쓰기 전에 조직 인증(Verify Organization)을 요구할 수 있어요. 그림이 안 만들어지면 OpenAI 콘솔 Settings → Organization에서 확인해 주세요.
5. 배포 주소에서 운영자로 로그인 → 오른쪽 위 이름 → **비밀번호 바꾸기**.
6. **그림체** 탭 → "추천 후보 6개 한 번에 넣기" → 후보마다 "AI로 견본 만들기"(같은 장면을 그림체별로 그려 줌)를 눌러 5회차 투표 준비.
7. 참여자에게 주소를 알려 주면 각자 **가입하기**에서 이름·휴대폰 번호·비밀번호를 넣고 개인정보 동의 후 신청합니다(과정이 하나라 고를 것 없음). 운영자는 **참여자** 탭 "승인 기다리는 중"에서 **승인**합니다. 모집 명단이 있으면 "여러 명 한꺼번에 등록하기"로 넣어도 돼요.

## 새로 들어간 기능 (8회차 계획서 맞춤)

| 회차 | 앱에서 쓰는 곳 |
|---|---|
| 1회 이야기 지도 | **이야기 지도** 탭: 지도에서 자리를 누르고 장소·언제·기억을 적어요. 함께 수업하는 분들의 장소도 보여요(내 장소는 주황, 다른 분은 파랑). 내 장소를 누르면 "이 기억으로 AI 인터뷰", "내 책에 쪽 만들기" |
| 2회 AI 인터뷰 | **AI 인터뷰** 탭: AI가 한 번에 하나씩 질문 → 대답 → "정리하기"로 글감·주제·독자·핵심 메시지 정리 → "내 책에 새 쪽으로 넣기", "12쪽 구성표에 주제 옮기기". 대화는 저절로 저장 |
| 3회 12쪽 구성표 | **내 책 쓰기 → 12쪽 구성표**: 1쪽 제목면 · 2~11쪽 글/그림 번갈아 · 12쪽 지은이 소개. "AI에게 흐름 제안받기"가 빈 칸을 채워 주고, "이 구성표로 12쪽 만들기"를 누르면 쪽 틀까지 골라진 12쪽이 생겨요 |
| 5회 그림체 투표 | **그림체** 탭: 참여자는 한 표(바꿀 수 있음), 강사·운영자는 후보 더하기·견본 만들기/올리기·"이걸로 정하기" |
| 5~6회 AI 그림 | 쪽의 그림 칸 → **AI로 그림 만들기**: 구성표에 적은 그림 장면이 미리 들어가 있고, 정해진 공동 그림체가 먼저 골라져 있어요. 그림 칸 모양에 맞춰 세로/가로/정사각을 골라 두고, 만든 그림은 사진첩에도 저절로 담겨요. 사진첩 탭에서도 만들 수 있어요 |

- **하루 한도(참여자 1명)**: AI 그림 10장(중간 화질), AI 인터뷰 80번, AI 교정 20번. 강사·운영자는 제한 없음. 숫자는 `schema.sql`의 `ai_check`(그림 10·인터뷰 80)와 `proof_check`(20)에서 바꿀 수 있어요.
- **비용 어림** (만들 때 알고 있던 gpt-image-1 가격이라 지금은 바뀌었을 수 있어요. OpenAI 가격표로 꼭 확인): 중간 화질 정사각 1장 약 4센트, 세로·가로 1장 약 6센트(80~90원). 10명이 하루 10장씩 수업일 10일 동안 다 쓰면 최대 1,000장 ≈ 60달러 안팎, 실제로는 훨씬 적게 들어요. OpenAI 콘솔에서 월 사용 한도(Limits)를 걸어 두세요.
- **AI 동의**: 첫 로그인 동의의 "AI 기능" 하나로 교정·인터뷰·그림을 함께 받아요(Claude·OpenAI로 글이 보내진다는 안내 포함). 동의하지 않은 참여자는 AI 기능만 막혀요(서버에서도 막음).
- 이야기 지도 바탕은 OpenStreetMap이라 인터넷이 필요해요. 지도를 못 불러오면 목록과 "장소 적기"만 보여요.

## 쓰는 흐름

- **참여자**: 처음 들어오면 8회차 수업 되짚기 카드와 "12쪽 구성표로 한 번에 시작하기"가 나옵니다. 질문을 누르면 질문이 적힌 새 쪽이 생기고, 그 회차에 맞는 쪽 틀이 골라져 있습니다.
  쪽마다 틀(15가지)을 고르고, 글을 쓰고, 사진·그림을 넣습니다. 1초 뒤 자동 저장.
- **교육자료**: "교육자료" 탭에서 강사·운영자가 회차마다 수업 자료(PDF·그림·슬라이드·한글·영상 등 파일 50MB까지, 또는 링크)를 올립니다. 참여자는 자기 과정의 자료와 "모든 과정 공통"을 보고 제목을 눌러 열거나 내려받습니다. 그림 파일(JPG·PNG)은 한 회차에 모아 "슬라이드로 보기"로 열립니다: 옆으로 넘기기, 좌우 버튼, 전체화면, 두 번 두드려 확대, 폰을 가로로 돌리면 가로에 맞춰 보여요. 강사·운영자는 "순서 바꾸기"(끌어 놓기 또는 ▲▼)와 "이름 순으로 정렬"로 슬라이드 순서를 정합니다. 여러 장을 한꺼번에 올리면 파일 이름 순(1, 2, 3…)으로 자동 정렬됩니다. 파일은 주소를 아는 사람이면 누구나 열 수 있는 공개 저장소에 올라가니, 외부에 나가면 안 되는 자료는 올리지 마세요.
- **회차 사진 (강사·운영자)**: "회차 사진" 탭에서 과정·회차마다 사진을 여러 장 한꺼번에 올립니다. 회차를 모르는 사진은 과정별 "구분 안 함"(그 과정 참여자만 봄)이나 "전체 공용"(과정 구분 없이, 모든 참여자가 봄)에 올리면 되고, 사진마다 "옮기기…"로 나중에 회차를 정해 줄 수 있습니다. 방향이 틀린 사진은 ↺ ↻(90도씩)로 돌리면 원본이 바뀝니다.
- **사진첩 (참여자)**: "사진첩" 탭 → 회차 사진("구분 안 함"·"전체 공용" 포함)에서 내 사진을 찾아 "담기"로 가져가거나, 내 사진을 직접 올립니다. 사진첩에서 돌리면 내 사본만 바뀌고 원본은 그대로입니다.
  쪽의 사진 칸에서 "사진첩에서 고르기"를 누르면 사진첩과 회차 사진을 함께 보고 고를 수 있습니다(회차 사진을 고르면 사진첩에도 담김). 넣은 뒤에도 ↺ ↻로 돌릴 수 있습니다.
- **글꼴·크기·굵게**: 쪽마다 "이 쪽의 글꼴·크기·굵게"에서 고릅니다(글 칸 전체에 적용). 글꼴은 `fonts.js`에 적힌 24개(모두 Google Fonts, OFL 라이선스라 인쇄·배포 가능)이고, 줄을 지우거나 더하면 바로 반영됩니다. "굵게"는 진짜 굵은 글씨가 있는 글꼴에서만 켤 수 있고, 없는 글꼴은 억지로 굵게 만들지 않습니다(목록에 "(굵게 없음)"으로 표시). 글꼴은 고를 때 그때그때 인터넷에서 불러오므로, PDF를 만드는 PC도 인터넷에 연결돼 있어야 합니다.
- **내 마음대로 쪽 (15번째 틀)**: 글 상자·그림 상자를 원하는 만큼 넣고, 미리보기에서 끌어서 옮기고 오른쪽 아래 모서리로 크기를 바꿉니다(숫자 mm로도 가능). 상자마다 글꼴·크기·굵게·정렬을 따로 정합니다. 다른 틀로 쓴 쪽을 이 틀로 바꾸면 글과 그림이 상자로 옮겨집니다.
- **안전영역**: 미리보기에 재단선(빨강)과 안전영역(가장자리 10mm 안쪽, 파란 점선)이 기본으로 보이고 "안전영역 켬/끔"으로 끌 수 있습니다. 인쇄에는 나오지 않습니다. 책 미리보기 점검에서 안전영역 밖으로 나간 글 상자를 알려 줍니다.
- **선생님께 요청**: 참여자가 "선생님께 요청"을 누르고 쪽의 한 곳을 찍으면 번호 핀이 꽂히고 할 말을 적습니다. 강사·운영자는 현황판의 "요청" 칸에서 건수를 보고, 그 사람 책을 열어 핀을 누르면 답글을 달고 "처리했어요"로 표시합니다. 참여자는 핀 색으로 상태(빨강 기다리는 중 → 파랑 답글 있음 → 회색 처리됨)를 보고 핀을 눌러 답글을 읽습니다. 핀은 책에 인쇄되지 않습니다.
- **줄바꿈**: 엔터 한 번은 새 문단, 두 번은 한 줄 띄우기, "- "나 "1. "로 시작하면 목록처럼 가지런히 맞춰집니다. 시는 행·연이 그대로 들어가고, 긴 행은 살짝 들여서 이어집니다. 쓰는 칸 아래에 틀마다 요령이 보입니다.
- **넘침**: 글이 칸을 넘치면 빨간 경고가 뜹니다. "넘친 글을 새 쪽으로"를 누르면 다음 쪽으로 옮겨집니다.
- **AI 교정**: 쪽마다 "AI 교정 받기" → 맞춤법만 / 어색한 문장까지 → 반영할 것만 골라 반영. "교정 되돌리기"로 원래대로 돌아갈 수 있습니다. 참여자 한 명당 하루 20번까지(강사·운영자는 제한 없음).
- **마무리**: "책에 실릴 모양 보기"로 확인한 뒤 "다 썼어요. 책에 실어도 좋아요"를 체크. 그 뒤 글을 고치면 체크가 자동으로 풀립니다.
- **강사·운영자**: 현황판에서 과정별로 누가 몇 쪽 썼는지 보고, 이름을 누르면 그분 책을 함께 고칠 수 있습니다(어르신 도와드릴 때).
- **책 만들기**: 과정을 고르고 → 싣는 순서·책 정보·표지 그림 → "책 미리보기와 PDF" → 위쪽 "확인할 것"을 해결 → PDF로 저장.

## 데이터 보호

- **같이 고칠 때**: 한 작품을 두 곳(폰과 PC, 참여자와 강사)에서 동시에 고치면 나중에 저장하려는 쪽에 "다른 곳에서 먼저 고쳤어요" 창이 뜹니다. "새로 불러오기"나 "여기 것으로 덮어쓰기" 중에 고르면 되고, 말없이 덮어써지지 않습니다.
- **공용 기기**: 로그인 화면에서 "여러 사람이 같이 쓰는 기기예요"를 체크하면 창을 닫거나 20분 동안 쓰지 않을 때 자동으로 로그아웃됩니다(서버 쪽 로그인도 12시간 뒤 끝남). 상상창고 태블릿·PC에서는 꼭 체크하게 해 주세요.
- **백업**: 운영자는 참여자 탭의 "전체 백업 내려받기"로 참여자·작품·책 정보·사진 목록을 JSON 파일 하나로 받을 수 있습니다. 책을 넘기기 전과 사업이 끝날 때 한 번씩 받아 두세요.

## 첫 로그인 안내·동의

참여자는 처음 로그인할 때 안내 화면을 거칩니다. 사진 안내는 "읽고 확인했어요"를 체크해야 시작할 수 있고, AI 기능(교정·인터뷰·그림) 동의는 선택입니다.
동의하지 않은 참여자는 글쓰기·사진·이야기 지도·책 만들기는 모두 쓸 수 있고 AI 기능만 막힙니다(서버에서도 막음, 강사가 대신 교정할 때도 참여자 동의 기준).
"AI 교정 받기"를 누르거나 오른쪽 위 이름 메뉴에서 언제든 동의하거나 거둬들일 수 있습니다. 운영자는 참여자 탭의 "안내·동의" 칸에서 확인 여부와 날짜를 봅니다.
안내 글은 `config.js`의 `consent`로 바꿀 수 있고, `version`을 바꾸면 모든 참여자에게 다시 받습니다. 문구는 재단 개인정보 담당자 검토를 거치는 것을 권합니다.

## PDF 저장 (PC 크롬 권장)

책 만들기에서 PDF를 두 개 만들어 인쇄소에 함께 넘깁니다. 각 미리보기의 "PDF로 저장하기" → 인쇄 창에서 대상 **PDF로 저장**(용지 크기는 자동). 안 되면 "설정 더보기"에서 여백 **없음**, **배경 그래픽** 체크.

- **내지 PDF**: 신국판 152×225mm. 속표지 → 빈 쪽 → 차례 → 책을 펴내며(쓴 경우) → 작가별 여는 쪽 + 본문 → 함께 만든 사람들 → (빈 쪽) → 판권. "내지 쪽수 맞추기"(기본 4의 배수)만큼 빈 쪽을 더해 맞추고, "작가마다 첫 쪽을 오른쪽에서 시작"을 끄면 빈 쪽이 줄어듭니다. "쪽 끝까지 가득" 쪽이 있으면 "내지에 도련 3mm 넣기"를 켜세요. 사진이 잘리면 안 될 때는 "안전영역 안에 가득" 틀을 쓰면 됩니다(둘레에 흰 여백).
- **펼침 표지 PDF**: [날개] 뒤표지 · 책등 · 앞표지 [날개]를 한 장으로, 도련 3mm 포함. 책등 폭은 인쇄소가 알려 준 값을 넣는 것이 가장 정확하고, 없으면 내지 쪽수 × 종이 한 장 두께로 어림합니다. ISBN을 넣으면 뒤표지에 "바코드 자리"가 생기니 받은 바코드로 채우세요.
- 인쇄소에 미리 물어볼 것: 책등 폭(또는 내지 종이 두께), 표지 날개 유무와 폭, 도련 크기, 쪽수 배수, 받는 파일 형식. 브라우저 PDF는 RGB라서 CMYK가 필요하면 인쇄소에 변환을 부탁하세요.

## 사진 해상도

앱이 사진마다 "인쇄하기 좋아요 / 조금 작아요 / 너무 작아요"로 알려 줍니다. 휴대폰 사진이나 생성형 AI 기본 크기(1024px 이상)면 대부분 괜찮고, "쪽 끝까지 가득"·"안전영역 안에 가득" 쪽에는 긴 변 2,500px 이상을 권합니다.

## 보안·개인정보

- 표는 밖에서 직접 읽을 수 없고, 모든 요청은 로그인 토큰을 확인하는 함수를 거칩니다. AI 교정 함수도 같은 토큰을 확인합니다.
- 비밀번호는 암호화해 저장하고, 5번 틀리면 10분 동안 잠깁니다. 운영자가 참여자 정보를 저장하면 잠김이 풀리고, 잊은 사람은 "고치기"에서 새 비밀번호를 정해 줄 수 있습니다.
- 휴대폰 번호는 운영자만 봅니다(참여자 탭, 백업 파일). 가입 화면의 개인정보 문구(`config.js`의 `consent.privacy`로 바꿀 수 있음)대로 책 제작이 끝나면 지워 주세요.
- 사진은 무작위 주소로 저장됩니다. 얼굴이 나온 사진은 동의를 받은 것만 올려 주세요.
